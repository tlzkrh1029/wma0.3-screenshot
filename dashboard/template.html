기준선 환산값

    데이터와 한계

    • 모든 값은 TradingView 차트 데이터입니다. 여섯 티커의 1D, 3D, 1W 봉을 TradingView에서 그대로 받아 왔으므로, 봉 경계와 종가가 TradingView 차트와 같습니다.
    • 데이터는 GitHub Actions가 로그인 쿠키로 TradingView에 접속해 받아 옵니다. TradingView가 공식 제공하는 방법이 아니어서 언제든 막힐 수 있습니다.
    • WMA 200은 Pine Script의 ta.wma(close, 200)과 같은 식(최근 봉 가중치 200부터 1까지)으로 계산했습니다.
    • 각 타임프레임의 마지막 봉은 수집 시각 기준으로 진행 중인 봉입니다. 새 데이터는 수집을 다시 돌리고 보드를 다시 게시해야 반영됩니다.
